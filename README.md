# Article labs

Los experimentos de los artículos del [blog de DevExpert](https://devexpert.io/blog): el código, los encargos, los tests ocultos y los resultados de cada ejecución, para que cualquiera pueda comprobar de dónde salen los números o repetirlos con su versión de cada agente.

Cada experimento vive en su carpeta, con la fecha en la que se midió, su README (qué se midió, cómo, con qué versiones y sus límites) y el código tal como se usó. Si un experimento se repite más adelante, se hace en una carpeta nueva y la anterior se queda como estaba.

| Experimento | Artículo | Qué mide |
|---|---|---|
| [2026-11-context-engineering](2026-11-context-engineering) | [Context engineering](https://devexpert.io/blog/context-engineering) | Qué carga cada agente al empezar y qué cambia cuando el `AGENTS.md` hace de mapa o lo lleva todo dentro |
| [2026-11-mcp](2026-11-mcp) | [MCP: qué es y cuándo compensa](https://devexpert.io/blog/que-es-mcp) | Cuánto contexto ocupan los servidores MCP y qué cambia al hacer la misma tarea con MCP, con una CLI o con una skill |

Agentes medidos hasta ahora: Claude Code, Codex y OpenCode, cada uno sin la configuración de su usuario. Las versiones y los modelos de cada experimento están en su README.
